# homebrew-lookatmyquant-gui

Homebrew tap for [LookAtMyQuant-Gui](https://github.com/Shreyas-Dasari/LookAtMyQuant-Gui), a Mac desktop launcher for running LookAtMyQuant models locally. Run these two commands to install it (add `--no-quarantine` only if you are on an older Homebrew release that rejects unsigned apps):

```bash
brew tap Shreyas-Dasari/lookatmyquant-gui
brew install --cask lookatmyquant-gui
```
